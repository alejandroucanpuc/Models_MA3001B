Metodología Box-Jenkins

Modelos ARIMA / SARIMA

Del dominio de la estadística clásica al forecasting de series de tiempo complejas.

1. Fase de Repaso

El Espacio de los Procesos Estacionarios

El formalismo de Box-Jenkins se basa en el Operador de Rezago ($B$), definido como:

$$B y_t = y_{t-1}$$

A partir de este operador, construimos los procesos fundamentales:

  • AR(p): $\phi_p(B)y_t = \varepsilon_t$. Raíces de $\phi(z)=0$ deben estar fuera del círculo unitario para asegurar estacionariedad.
  • MA(q): $y_t = \theta_q(B)\varepsilon_t$. Siempre estacionarios, requieren invertibilidad para representarse como AR($\infty$).
  • ARMA(p,q): Combinación de ambos: $\phi(B)y_t = \theta(B)\varepsilon_t$.

2. Modelos ARIMA

Integración y Homogeneidad

Cuando la serie no es estacionaria en media (presenta tendencia), introducimos el operador de diferencia $\nabla = (1-B)$.

Definición formal de un ARIMA(p,d,q):

$$\phi_p(B)\nabla^d y_t = \theta_q(B)\varepsilon_t$$

Intuición

El parámetro $d$ representa cuántas "derivadas discretas" aplicamos hasta que el proceso se vuelve estacionario.

Típicamente $d \in \{0, 1, 2\}$. Si diferenciamos demasiado, inducimos sobrediferenciación y ruido artificial.

3. Modelos SARIMA

La Dimensión Estacional

Para series con periodicidad $s$ (ej. $s=12$ para datos mensuales), extendemos el modelo de forma multiplicativa sumando componentes estacionales $P, D, Q$:

SARIMA $(p,d,q) \times (P,D,Q)_s$ $$\phi_p(B)\Phi_P(B^s)\nabla^d \nabla_s^D y_t = \theta_q(B)\Theta_Q(B^s)\varepsilon_t$$

Identificación: Observamos "spikes" (picos significativos) en las gráficas ACF y PACF ubicados exactamente en múltiplos de $s$ (lags 12, 24, 36...).

4. Metodología Box-Jenkins

El Ciclo Iterativo

1. Identificación

  • Estabilizar varianza (Log o Box-Cox).
  • Determinar $d$ y $D$ vía Test ADF (Dickey-Fuller).
  • Analizar ACF/PACF para $p,q,P,Q$.

2. Estimación

  • Ajustar coeficientes mediante MLE (Máxima Verosimilitud) o Mínimos Cuadrados No Lineales.

3. Diagnóstico

  • Residuales $\hat{\varepsilon}_t$ deben ser ruido blanco.
  • Test Ljung-Box: $H_0$: Los residuales son independientes.

4. Forecasting

  • Predicciones de Mínimo Error Cuadrático Medio (MMSE).
  • Generación de intervalos de confianza.

5. Implementación en Python

Script 1: Diagnóstico de Estacionariedad


import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from statsmodels.tsa.stattools import adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

# Cargar datos (ejemplo Serie G de Box-Jenkins)
data = pd.read_csv('airline_passengers.csv', index_col='Month', parse_dates=True)

# 1. Función de Test ADF
def check_stationarity(series):
    result = adfuller(series)
    print(f'ADF Statistic: {result[0]:.4f}')
    print(f'p-value: {result[1]:.4f}') # Si p < 0.05, es estacionaria

# Aplicar log y diferencia estacional (s=12) para remover tendencia/estacionalidad
data['log_passengers'] = np.log(data['Passengers'])
data['diff_seasonal'] = data['log_passengers'].diff(12).dropna()

check_stationarity(data['diff_seasonal'])

# 2. Identificación visual (ACF / PACF)
fig, ax = plt.subplots(1, 2, figsize=(12, 4))
plot_acf(data['diff_seasonal'], ax=ax[0], lags=40)
plot_pacf(data['diff_seasonal'], ax=ax[1], lags=40)
plt.show()

Script 2: Ajuste SARIMA y Diagnóstico


from statsmodels.tsa.statespace.sarimax import SARIMAX

# Ajuste del modelo SARIMA(0,1,1)(0,1,1)12 (Modelo clásico 'Airline')
model = SARIMAX(data['log_passengers'], 
                order=(0, 1, 1), 
                seasonal_order=(0, 1, 1, 12))
results = model.fit()

# Resumen estadístico (AIC, BIC, Coeficientes, Ljung-Box)
print(results.summary())

# Diagnóstico visual de residuales (Normalidad, ACF residual)
results.plot_diagnostics(figsize=(15, 12))
plt.show()

# Pronóstico MMSE (Próximos 12 meses)
forecast = results.get_forecast(steps=12)
forecast_df = forecast.summary_frame() # Incluye IC al 95%
print(forecast_df)
